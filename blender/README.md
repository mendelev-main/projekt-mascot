# Blender asset pipeline

The current canonical static model is **v0.5**. Geometry, material names,
review renders and the runtime GLB are generated by one script, so the binary
assets can always be reproduced and inspected.

## Requirements and generation

Supported: Blender 4.x and Blender 5.x.

```bash
blender --background --python blender/scripts/build_mascot.py
```

On macOS systems where background Eevee rendering is unavailable, open Blender,
switch to the Python console and run:

```python
import runpy; runpy.run_path("/absolute/path/to/blender/scripts/build_mascot.py")
```

The script writes:

```text
blender/projekt_mascot_v05.blend
blender/renders/mascot_front_v05.png
blender/renders/mascot_three-quarter_v05.png
blender/renders/mascot_side_v05.png
blender/renders/mascot_rear_v05.png
blender/renders/mascot_top_v05.png
blender/renders/mascot_hero_v05.png
models/projekt-mascot-v05.glb
```

The camera, ground and studio lights remain in the `.blend`. Only the
`MascotRoot` hierarchy is exported to GLB.

## Review result

v0.5 is the first production-look pass. It adds a layered outer/inner glass
shell, warmer edge highlights, denser dark coffee, a thinner crema surface and
band, more varied bubbles, and separate face core/glow geometry. The Cycles
hero render is the high-quality visual reference; the five Eevee views remain
the fast geometry review set.

The next visual pass may refine glass thickness, internal coffee detail and
crema microstructure without changing the exported semantic control nodes.
