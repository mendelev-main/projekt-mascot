# Blender asset pipeline

The current canonical static model is **v0.4**. Geometry, material names,
review renders and the runtime GLB are generated by one script, so the binary
assets can always be reproduced and inspected.

## Requirements and generation

Supported: Blender 4.x and Blender 5.x.

```bash
blender --background --python blender/scripts/build_mascot.py
```

On macOS systems where background Eevee rendering is unavailable, open Blender,
switch to the Python console and run:

```python
import runpy; runpy.run_path("/absolute/path/to/blender/scripts/build_mascot.py")
```

The script writes:

```text
blender/projekt_mascot_v04.blend
blender/renders/mascot_front_v04.png
blender/renders/mascot_three-quarter_v04.png
blender/renders/mascot_side_v04.png
blender/renders/mascot_rear_v04.png
blender/renders/mascot_top_v04.png
models/projekt-mascot-v04.glb
```

The camera, ground and studio lights remain in the `.blend`. Only the
`MascotRoot` hierarchy is exported to GLB.

## Review result

v0.4 establishes the sealed horizontal capsule, transparent shell, dark coffee
mass, crema surface and band, bubbles, glowing face, stable object names and a
sub-3 MiB runtime asset. The render set covers all five required review angles.
